Analyze Meter runs the real feature-engineering + Random Forest + K-means pipeline on the server — it can't be approximated in the browser. Connect the backend (see the status pill, top right) to use this feature.
How to use this
  1. Enter a CONS_NO. SGCC has no customer name or category, and the model never sees either.
  2. Paste one row per day: date, daily kWh. Upload a .csv, or click Load example from dataset.
  3. Click Run analysis. This sends your readings to the server, which runs the actual feature_engineering.py pipeline and the trained Random Forest + K-means models — nothing is computed in the browser.
  4. Nothing is saved — this is a one-off "what if" check, not meter registration.

How is this score calculated?
Risk score = 0.55 × RF probability + 0.45 × K-means anomaly score
risk score ≥ 0.72 → HIGH
risk score ≥ 0.42 → MEDIUM
otherwise → LOW
These weights and thresholds are read live from the server's risk_score.py — this panel is not a separate copy of the logic.
